The end-to-end framework bridges biopotential acquisition with real-time digital signal processing and telemetry:

  • Analog Front-End (MAX30001 / AD8232) for low-noise Lead-I ECG signal conditioning.

// Algorithm Pipeline

Signal Processing Sequence

1. R-Peak Detection

Pre-filtering and adaptive thresholding detect accurate QRS complex locations and peak amplitudes from raw ECG.

2. EDR Signal Extraction

Amplitude variations across sequential R-peaks are extracted to construct the ECG-Derived Respiration (EDR) signal.

3. Respiration Rate Extraction

Time-domain MPD (Mean, Prominence, Distance) algorithm isolates valid respiratory cycles from the EDR waveform.

// Research Motivation

Why Textile Electrodes?

Conventional Ag/AgCl gel electrodes provide high signal quality in clinical settings but are fundamentally unsuited for daily, continuous wearable monitoring. The conductive gel dries over time, leading to signal loss, skin irritation, and mandatory frequent replacement.

This project investigates embroidered textile ECG electrodes fabricated with silver-coated conductive thread as a durable, breathable, and garment-integrated alternative. By optimizing embroidery fill geometry and characterizing the dynamic skin-electrode interface via Electrochemical Impedance Spectroscopy (EIS), this work demonstrates that dry textile interfaces achieve clinical-grade signal fidelity as skin adaptation occurs naturally over time.

Cross-Lead Reconstruction Non-Linear KRR-RBF Kernel 10-Subject Study (5M / 5F) r = 0.99 P-Wave Correlation
// Research Motivation

Anatomical Limits & Solution Architecture

The Placement Challenge: In wearable health monitoring, chest belts naturally align with the V1–V2 precordial electrode positions. However, because the primary cardiac atrial depolarization vector runs horizontally across the chest, electrodes in the V1–V2 orientation often record an attenuated, flattened, or visually masked P-wave. This limitation stems purely from electrode placement geometry rather than a defect in the textile material itself.

Cross-Lead Reconstruction Strategy: To retain clinical diagnostic capability (such as detecting Atrial Fibrillation or measuring P-R intervals) in everyday commercial wearable belts, an auxiliary Lead I Ag/AgCl reference was recorded concurrently. Using non-linear Machine Learning models—specifically Kernel Ridge Regression with a Radial Basis Function kernel (KRR-RBF)—the true atrial P-wave morphology was reconstructed into the textile V1–V2 channel across 10 human subjects (5 Male, 5 Female) with remarkable precision.

// Research Overview

Framework Architecture & Motivation

Surface electromyography (sEMG) hand gesture recognition is vital for advanced prosthetics and human-computer interaction (HCI). However, embedded hardware deployment faces a severe trade-off between computational complexity and real-time execution bounds (< 125 ms).

This work introduces a multi-domain framework combining Time-Domain (TD), Frequency-Domain (FD), and Non-Linear Dynamical (NL) features across dual-channel sEMG. Through two-stage feature selection (ANOVA + Redundancy Reduction) and latency profiling, the system achieves state-of-the-art gesture discrimination within embedded real-time timing budgets.

Real-Time Execution

Restricting per-feature extraction latency to ≤ 2 ms enables reliable real-time prediction within 10.3 ms total execution time.

Multi-Domain Synergy

Combines classical statistical metrics with non-linear entropy features to capture transient muscle activation dynamics.

Redundancy Elimination

ANOVA and pairwise correlation filtering prune feature space by 58.3%, eliminating computational overhead.

// Research Motivation

The Challenge in Wearable Cardiac Monitoring

Conventional ECG denoising relies heavily on noise-specific algorithms such as notch filters, wavelet transforms, adaptive filtering, or empirical mode decomposition (EMD). Selecting, tuning, and chaining the appropriate method for unknown, real-time ambulatory ECG recordings remains a major practical challenge in wearable health technology.

To solve this fundamental limitation, we present MG-DBNet—a single unified deep learning framework capable of end-to-end signal conditioning across diverse noise modalities without requiring prior noise classification or manual hyperparameter tuning.

Wearable Deployment

// Research Motivation

Precision Timing in Surface Electromyography

Conventional sEMG onset detection relies heavily on Di Fabio's algorithm (Threshold = μ + h · σ), where μ and σ are baseline statistics and h is a preset multiplier. In literature, h varies widely from 0 to 30, making threshold selection highly sensitive to background noise and subject variability.

By combining the Shannon Teager–Kaiser Energy Operator (STKEO) with a whole-signal threshold (Tmsr = Tm + Tsd + Trms), Project 07 eliminates dependency on quiet baseline selection and variable h values, delivering precise, expert-aligned muscle activation timing.

// Core Innovations

Why STKEO & Additive Thresholding?

TKEO Energy Tracking

Standard TKEO: Pz(n) = x²(n) - x(n-1)x(n+1). Tracks instant changes in amplitude and frequency simultaneously.

Shannon Operator (STKEO)

STKEO: Ps(n) = Pz · log(Pz). Non-linearly magnifies active burst energy relative to baseline noise.

Whole-Signal Tmsr

Calculates dynamic limits based on the complete signal duration without selecting noise-free baseline windows.

Baseline Independent

Eliminates the preset 'h' factor, yielding consistent timing results across all 103 evaluated sEMG signals.
